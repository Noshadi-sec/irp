# IRP documentation

**Build any paper. Prove every claim.** IRP lets your coding agent turn a
research paper into working code, run it, and prove claim by claim how close it
gets, with a report you can check without trusting the agent.

## Start with one command

```bash
uvx irp-agents setup
```

Choose your agents, review the plan, approve it, and restart the agents. Then
ask: "Build arXiv 2501.12345 and check Table 2."
