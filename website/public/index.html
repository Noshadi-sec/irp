Build any paper.
Prove every claim.

IRP lets your coding agent turn a research paper into working code, run it, and prove claim by claim how close it gets. You get the code and a report you can check without trusting the agent.

uvx irp-agents setup

Then ask your agent: Build arXiv 2501.12345 and check Table 2.

How it works

Claims first

Every number the paper claims is recorded, with where it appears and the bar for reproducing it, before any code is written.

Numbers only from runs

A result counts only if a full run printed it. Typed numbers and shortened runs never count.

Every step on the record

An append-only, hash-chained evidence log. Edit it and irp verify says where.

Your agent, your machine

Works with Claude Code, Codex and Cursor. IRP never calls a model; paid GPUs only after your approval.
