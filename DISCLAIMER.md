# Disclaimer

## Responsible use

IRP is built for lawful research and education: rebuilding published
computational methods, checking reported results, teaching, and improving the
reproducibility of science.

The IRP project does not support, and will not help with:

- wet-lab protocols, or work that could contribute to biological, chemical,
  nuclear or radiological weapons, or other dangerous science;
- redistributing papers, datasets, model weights or code in violation of their licenses;
- harassing authors, or publishing "not reproduced" results without the context
  this project requires (see below);
- evading the usage policies or safety measures of AI model providers.

Requests for help with these uses will be closed without response in issues and
discussions.

## Verdicts are evidence about one run

An IRP verdict describes what one implementation, built from the paper with
the recorded guesses, produced on one machine. "Not reproduced" means "not
reproduced by this run". It is not a finding that a paper is wrong, and it says
nothing about its authors' conduct. Missing details, hardware, data versions and
randomness can all change results.

Before publishing a "not reproduced" result about someone's paper, contact the
authors, share the report and the guess list, and record the contact in the
study. Describe the result accurately and include its limitations.

## Running code

IRP runs code you or your agent write, and installs third-party packages,
with your permissions. A virtual environment is not a sandbox. You are
responsible for the code you choose to run, the data it accesses, and its
effects on your machine and accounts. Use Docker or a disposable environment for
code you do not trust.

## Paid compute

Paid compute runs only after you record a price and a budget and approve an
estimate. Estimates use the price you entered; providers bill by their own terms,
including image builds, storage and minimum charges. You are responsible for
your provider account and its charges.

## Papers, data and generated code

Papers and datasets keep their authors' licenses. IRP downloads papers for
your own reading and never redistributes them. Code your agent writes from a
paper may still be covered by the paper's patents or other rights: a published
method can be patented. Check before using an implementation in a product. This
is not legal advice.
